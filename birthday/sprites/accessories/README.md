# Krystal head-accessory sprites

Each PNG is a transparent 128×128 front-facing sprite, centered and scaled for
Krystal's standard expression sprites. The filename matches the existing outfit
ID in `js/features.js`. These are standalone art assets; no renderer wiring is
included.

Suggested anchor: center the image on Krystal's head center, then place the
sprite's vertical center near the top of her hair. Fine-tune per accessory after
the renderer is wired.
